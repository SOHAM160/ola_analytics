# Ola Ride Analytics Dashboard

## Project Overview
Analyzed 40,000+ Ola ride booking records to identify trends in ride demand, cancellations, revenue, and customer behavior.

## Tools Used
- Excel
- SQL
- Power BI
- DAX

## Key Insights
- Ride demand trends
- Revenue analysis
- Cancellation analysis
- Customer ratings analysis
- Vehicle type performance
